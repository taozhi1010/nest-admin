# 路由搜索组件重构记录

## 重构时间
2026-04-06

## 重构目标
将原有的基于 Element Plus `el-select` 的简单下拉搜索组件，重构为类似 VitePress 风格的现代化模态框搜索体验。

## 重构前问题分析

原有 `HeaderSearch` 组件存在以下问题：
- 界面样式简陋，仅为一个简单的下拉框
- 缺少键盘快捷键支持（如 Ctrl+K）
- 搜索结果展示不够直观，仅有标题
- 缺少搜索历史记录功能
- 交互体验不够现代化

## 重构方案

### 1. 组件结构优化
- 将 `SearchModal` 作为 `HeaderSearch` 的子组件，放在 `components/HeaderSearch/components/` 目录下
- 逻辑抽离到 `useRouteSearch` composable 中，实现关注点分离

### 2. 新增文件

#### 搜索逻辑 Composable
**文件**: `src/composables/useRouteSearch.ts`

功能：
- 路由数据生成逻辑（从权限 store 获取路由并生成可搜索列表）
- Fuse.js 模糊搜索集成（继续复用已有的 fuse.js 库）
- 搜索历史记录管理（使用 localStorage，最多保存 5 条记录）
- 键盘导航逻辑（上下箭头、Enter 选择、ESC 关闭）

核心接口：
```typescript
export interface RouteSearchItem {
  path: string
  title: string[]  // 面包屑标题数组
  icon?: string
}

export function useRouteSearch(config?: SearchConfig) {
  // 返回搜索相关的状态和方法
  return {
    query,           // 搜索关键词
    results,         // 搜索结果
    activeIndex,     // 当前选中索引
    searchHistory,   // 搜索历史
    hasResults,      // 是否有结果
    isEmptySearch,   // 是否为空搜索
    handleSearch,    // 执行搜索
    resetSearch,     // 重置搜索
    navigateDown,    // 向下导航
    navigateUp,      // 向上导航
    selectCurrentResult, // 选择当前结果
    clearSearchHistory   // 清空历史
  }
}
```

#### 搜索模态框组件
**文件**: `src/components/HeaderSearch/components/SearchModal.vue`

功能特性：
- 使用 `Teleport` 挂载到 body，实现全屏遮罩效果
- 支持 Ctrl+K / Cmd+K 全局快捷键打开
- 支持键盘导航（↑↓ 箭头键、Enter 选择、ESC 关闭）
- 显示面包屑路径（层级标题展示）
- 显示路由路径和图标
- 搜索历史记录展示（无输入时显示）
- 空状态提示
- 键盘快捷键提示（Footer 区域）
- 平滑过渡动画（淡入淡出 + 缩放）

#### 搜索模态框样式
**文件**: `src/components/HeaderSearch/components/SearchModal.scss`

样式特点：
- 半透明遮罩背景（带模糊效果）
- 居中搜索框（大圆角设计）
- 键盘快捷键提示样式（kbd 元素）
- 结果项悬停和选中状态（浅蓝色高亮）
- 响应式适配（移动端全屏）
- 深色模式支持（通过 `prefers-color-scheme`）

### 3. 修改文件

#### HeaderSearch 组件
**文件**: `src/components/HeaderSearch/index.vue`

改动：
- 移除原有的 `el-select` 实现
- 改为使用 `el-input` 作为触发器（只读模式）
- 添加搜索图标和快捷键提示
- 集成 `SearchModal` 子组件
- 简化代码量从 175 行减少到 60 行左右

代码对比：
```vue

<el-select v-model="search" filterable placeholder="Search" 
           remote :remote-method="querySearch" @change="change">

</el-select>

<!-- 重构后 -->
<el-input readonly placeholder="搜索路由..." :prefix-icon="Search" @click="openSearch">
  <template #suffix>
    <span class="kbd">Ctrl K</span>
  </template>
</el-input>
<SearchModal ref="searchModalRef" />
```

## 注意事项

1. **向后兼容**: HeaderSearch 组件的对外接口保持不变，其他组件使用方式无需修改
2. **性能优化**: Fuse.js 初始化只在路由变化时执行，搜索结果使用计算属性
3. **键盘焦点管理**: 模态框打开时锁定背景滚动，关闭时恢复
4. **自动导入**: 利用 `unplugin-auto-import` 自动导入 Vue API
5. **国际化预留**: 搜索提示文本预留国际化支持（当前使用中文）
6. **存储限制**: 搜索历史记录最多保存 5 条，避免 localStorage 占用过多

本次重构成功将简单的下拉搜索升级为现代化的模态框搜索体验，参考 VitePress DocSearch 的设计，提供了更专业的用户界面和更高效的交互方式。通过 Composable 模式实现逻辑复用，代码结构更清晰，可维护性更强。

3. **信息展示**: 面包屑路径 + 路由路径，信息更丰富
