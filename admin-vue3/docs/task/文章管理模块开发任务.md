## 📋 项目现状分析

### ✅ 已完成部分
- 基础 API 接口已定义（增删改查）
- 基础页面框架已搭建（列表、表单、预览）

## 🎯 开发目标

构建一个功能完善的文章管理系统，支持：
- ✅ 文章的创建、编辑、删除
- ✅ Markdown 富文本编辑
- ✅ 图片上传和管理
- ✅ 文章状态管理（草稿/已发布/已下架）
- ✅ 实时预览功能
- ✅ 灵活的搜索和筛选

## 🔧 技术实现细节

### 使用的核心技术

| 技术 | 用途 | 版本 |
|------|------|------|
| Vue 3 | 前端框架 | ^3.3.0 |
| Element Plus | UI 组件库 | ^2.9.3 |
| TypeScript | 类型系统 | ^5.8.3 |
| md-editor-v3 | Markdown 编辑器 | ^6.4.1 |
| dayjs | 日期处理 | ^1.11.13 |
| Pinia | 状态管理 | 2.0.22 |
| zod | 数据验证 | ^4.3.6 |

### Composables 使用

- `useRequest`: HTTP 请求封装
- `useDict`: 数据字典管理
- `useValidator`: 表单验证
- `useMessage`: 消息提示封装
- `useCommon`: 通用工具函数（resetForm 等）

### 代码规范

1. **命名规范**:
   - 变量/函数: camelCase (`articleList`, `handleAdd`)
   - 组件名: PascalCase (`ArticleList`, `PreviewDrawer`)
   - 常量: UPPER_SNAKE_CASE (`MAX_TITLE_LENGTH`)

2. **文件组织**:
   ```
   src/views/game/article/
   ├── index.vue              # 主页面
   ├── components/
   │   ├── Preview.vue        # 预览组件
   │   └── ArticleEditor.vue  # 编辑器组件（可选拆分）
   ```

3. **API 调用**:
   - 统一使用 `request` composable
   - 错误处理在 API 层统一处理
   - 成功提示在页面层处理

## ⚠️ 注意事项和常见问题

### 1. 数据字典问题
**问题**: `sys_article_status` 字典加载失败或数据不正确

**排查步骤**:
1. 检查后端字典接口是否正常返回
2. 确认字典 key 是否正确（区分大小写）
3. 查看 `useDict` composable 的实现逻辑
4. 检查浏览器控制台网络请求

**解决方案**:
- 临时方案：硬编码状态选项
- 最终方案：修复字典加载逻辑

---

### 2. Markdown 内容存储
**问题**: Markdown 内容包含特殊字符，可能导致存储或显示问题

**解决方案**:
- 后端存储时使用 TEXT 或 LONGTEXT 类型
- 前端显示时使用 `v-html` 或专门的 Markdown 渲染组件
- 注意 XSS 防护，对内容进行 sanitize 处理

---

### 3. 图片上传路径
**问题**: 上传后的图片路径如何处理

**解决方案**:
- 后端返回完整的图片 URL
- 前端直接使用该 URL 显示
- 考虑 CDN 加速（生产环境）

---

### 4. 性能优化
**大数据量列表**:
- 使用虚拟滚动（如果文章数量超过 1000）
- 分页加载，每页 10-20 条
- 图片懒加载

**编辑器性能**:
- 大文档时分段渲染
- 防抖处理输入事件
- 避免频繁的状态更新

## 📌 附录

### A. 相关文章字段说明

| 字段名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| articleId | number | 否 | 文章ID（新增时为空） |
| title | string | 是 | 文章标题，最多25字符 |
| remark | string | 是 | 文章简介，最多200字符 |
| content | string | 是 | 文章内容（Markdown格式） |
| coverImage | string | 否 | 封面图片URL |
| author | string | 否 | 文章作者 |
| status | string | 是 | 文章状态：0-草稿，1-已发布，2-已下架 |
| publishTime | string | 否 | 发布时间 |
| columnId | number | 否 | 专栏ID（预留字段） |
| createTime | string | 否 | 创建时间（后端自动生成） |
| updateTime | string | 否 | 更新时间（后端自动更新） |

### B. API 接口列表

| 接口 | 方法 | 路径 | 说明 |
|------|------|------|------|
| 查询列表 | GET | `/game/article/list` | 支持分页和筛选 |
| 查询详情 | GET | `/game/article/:id` | 根据ID获取文章 |
| 新增文章 | POST | `/game/article` | 创建新文章 |
| 修改文章 | PUT | `/game/article` | 更新已有文章 |
| 删除文章 | DELETE | `/game/article/:id` | 删除指定文章 |
